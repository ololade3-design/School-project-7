System Settings Information

This module allows the administrator to configure important information required for the Smart Timetable Generation and Course Scheduling System.

The settings include the university name, faculty, department, administrator details, academic session and current semester.

The administrator can also back up all saved records or reset the system when necessary. All information is stored using Local Storage for demonstration purposes.

These settings are used throughout the system and can be modified at any time without affecting the overall application structure.
