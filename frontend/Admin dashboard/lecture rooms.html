Module Information

This module allows the administrator to add, edit, search and delete lecture rooms used for timetable scheduling.

Each lecture room contains information such as room code, room name, seating capacity, building and availability status.

The timetable generation module will automatically allocate lecture rooms based on their capacity and availability.

All lecture room records are stored in the browser using Local Storage for demonstration purposes.
