System Report Summary

This module provides a complete overview of all records stored in the Smart Timetable Generation and Course Scheduling System.

Administrators can monitor the number of courses, lecturers, students, departments, lecture rooms and generated timetables from a single dashboard.

Reports can be refreshed, printed or exported for documentation and presentation purposes.

The report information is automatically updated from Local Storage whenever records are added, edited or deleted.
